# 拼多多金币任务（喝水 + 商品视频 + 短剧）

目标：在多多视频的金币面板里完成三个任务：每日8次喝水赚钱、看商品视频得现金、看短剧领金币。奖励金额和按钮文字每天会变（去领取 / 去逛逛 / 去观看等），但任务名固定，按名字找卡片，不按按钮文字找。

## 省时省 token 的核心纪律

1. 每个任务只截屏两三次：进任务读一次倒计时 → 本地记住结束时刻 → 到点核对一次。**绝不轮询截屏等倒计时**。
2. 翻页、停留的节奏刻意不均匀（间隔随机 2~10 秒），禁止匀速滑动、固定间隔、连点。
3. 中途只在页面明显变了（弹窗、跳走）时才额外截屏处理。

## 步骤

1. 启动拼多多（com.xunmeng.pinduoduo），进入「多多视频」（底部第二个标签）。等待加载，处理「跳过 / 关闭」类广告弹窗，不要误点下载。
2. 点右上角的**金币悬浮按钮**（圆形金色，显示当日金币数，例如「331 金币」；数字每次不一样，位置固定，就在「我的现金」下方）。点开进入金币面板：上半部分是「我的金币 / 我的现金」，下面是任务列表（限时拼单、拼单等大额任务一概不碰）。
3. 任务一：每日8次喝水赚钱。点对应卡片的「去领取」进入喝水页：
   - 按页面流程点「喝水 / 打卡」按钮领当次奖励；弹出「恭喜获得 xx 金币」就点关闭或继续，再看还有没有可领的次数。
   - 一天共 8 次，但一次进入通常只能领当前已到账的那次；页面提示「下次喝水还需 xx 分钟」或倒计时未到时，把能领的领完就停，**不要挂机等待下一轮**。
   - 领完返回金币面板。若卡片按钮变成了「领取」，点它把金币收进余额。
4. 任务二：看商品视频得现金（浏览 xx 秒，奖励金额以页面为准）。点「去逛逛」进入商品视频流：
   - 截一次屏读右上角倒计时，本地记下结束时刻（常见 60 秒）。
   - 浏览期间翻页节奏不均匀：划一下停 2~8 秒；每条商品视频停留几秒就翻，不要一条看到底。
   - 约 65 秒后截屏核对一次：显示已完成 / 倒计时走完就返回金币面板。
5. 任务三：看短剧领金币（看 xx 秒）。点「去观看」进入短剧播放：
   - 同样读一次倒计时后本地计时；短剧是连续剧，**不要上滑换剧**，让它播。
   - 约 65 秒后截屏核对，完成后返回金币面板。
6. 每个任务返回后都顺手确认：对应卡片若显示「领取」就点掉领取；显示「已完成 / 明日再来」才算这个任务收工。
7. 三个任务都处理完即可 finish，summary 按任务逐条写「任务名 → 已领取 / 已完成（本轮喝了 x 次，剩余 x 次待后续）」。
8. 风控注意：不碰限时拼单、拼单、签到日历以外的领取按钮；不点「换现金 / 提现」；弹出的「下载 / 开通 / 抽奖」一律关闭；不在任务页之外乱逛。

找不到金币按钮或某个任务卡时，用 ask_user 描述当前页面让用户指路；喝水任务如果显示今日 8 次已用完，跳过它只做另外两个，并在 summary 里注明。
